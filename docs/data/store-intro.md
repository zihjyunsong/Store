# 甜點小店介紹文案

## 首頁標語

法式手藝。
日常甜點。
剛剛好的可愛。

我們做小巧、細緻、不膩口的甜點。

給想好好生活的人。
也給需要一點甜的人。

## 關於小店

這是一間溫暖但不拖泥帶水的甜點小店。

店主剛從法國學成回國。

她把法式甜點的技法帶回來，
也把甜度調得更適合日常。

漂亮要有。
好吃更重要。

## 我們的甜點

- 法式技法，日常口味。
- 小批量製作，新鮮出爐。
- 甜度清爽，不厚重。
- 外型可愛，但不只可愛。
- 適合送禮，也適合自己偷吃。

## 品牌個性

可愛，但不幼稚。

溫柔，但有節奏。

法式，但不距離感。

這裡的甜點，
想成為你日常裡很小、很亮的一件事。

## 頁尾小語

今天也要吃點甜。
